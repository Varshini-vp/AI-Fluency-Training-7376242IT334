# Day 2 – Reasoning and Acting

## Objective

This experiment compares three approaches for solving problems using an AI model:

1. Direct Prompting
2. Chain-of-Thought (CoT)
3. ReAct (Reasoning and Acting)

The experiment also includes a Self-Consistency test to observe how repeated model responses change with different temperature settings.
